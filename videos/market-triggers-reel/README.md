# Market triggers reel

60s vertical (1080×1920) Hinglish news reel built with Remotion.

- Copy lives in `src/data.ts`; layouts and timing in `src/Reel.tsx`.
- Presenter photos are not committed: put `desk.jpg` and `portrait.jpg` in `public/img/`.
- Render: `npm install && npx remotion render src/index.ts Reel out/market-triggers-reel.mp4`

Audio: BGM "Tonight" (Mixkit Stock Music Free License) and Mixkit SFX — see `assets/audio/ATTRIBUTION.md`
and `template/public/audio/ATTRIBUTION.md`.
